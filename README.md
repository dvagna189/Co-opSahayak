# 🤝 Co-OpSahayak

**AI-powered multilingual assistant for cooperative society members.**

Co-OpSahayak helps members understand **governance rules, bylaws, legal rights, procedures, and grievance processes** through simple, conversational guidance.

### ✨ Key Features

* 🤖 AI-powered conversational assistance
* 📚 RAG-based, document-grounded responses
* 🌐 Multilingual support
* 🔀 Intelligent query routing
* 📝 Step-by-step workflows
* 📢 Grievance assistance and letter generation

### 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Backend:** Python, Flask
* **AI:** Gemini
* **Architecture:** RAG + Routing + Structured Workflows

### 🎯 Goal

To make cooperative society information **simple, accessible, and actionable** for every member.

> **AI + RAG + Workflows for smarter cooperative society assistance.**
